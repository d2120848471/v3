阿里 V3 滑块 · 纯协议复现  —— Windows 免安装版使用说明
================================================================

仅用于获得明确授权的本地研究与协议验证环境。禁止用于批量解题、并发挑战、
同一挑战重试、规避第三方访问控制或任何未授权目标。


一、怎么用
----------------------------------------------------------------

1. 把整个文件夹解压出来（不要只复制 AliSlider.exe，运行时都在同级目录里）。
2. 双击 AliSlider.exe 将直接启动快速 HTTP API：5 并发、共享 HTTP 连接池，
   启动时会准备 5 个常驻设备会话，不再显示启动菜单。
3. 服务就绪后会打印接口文档链接，并自动使用默认浏览器打开：
   http://127.0.0.1:8000/docs
4. 在接口文档页填写参数并点击“发送请求”，页面和 EXE 窗口都会显示
   完整 JSON 返回。服务期间无需输入命令；在 EXE 窗口按 Ctrl+C 停止。

目标机器不需要安装 Python、Node.js 或 OpenCV，全都在包里。


二、接口调用
----------------------------------------------------------------

默认地址：http://127.0.0.1:8000/api/slider
接口文档地址：http://127.0.0.1:8000/docs
OpenAPI 描述：http://127.0.0.1:8000/openapi.json

PowerShell：

  Invoke-RestMethod -Uri "http://127.0.0.1:8000/api/slider" -Method Post `
    -ContentType "application/json" -Body '{"SceneId": "1ug4aptr"}'

curl（Windows 10 以上自带）：

  curl -X POST "http://127.0.0.1:8000/api/slider" ^
    -H "Content-Type: application/json" ^
    -d "{\"SceneId\":\"1ug4aptr\"}"

Python：

  import requests
  r = requests.post("http://127.0.0.1:8000/api/slider",
                    json={"SceneId": "1ug4aptr"})
  print(r.json())

浏览器直接打开（GET 等价写法）：

  http://127.0.0.1:8000/api/slider?SceneId=1ug4aptr

健康检查：http://127.0.0.1:8000/health


三、请求参数（都可省略）
----------------------------------------------------------------

  SceneId      验证码场景 ID
  proxy        本轮全部出网走该代理；支持 ip:port、完整 URL、带账号密码的写法
  prefix       验证码实例域名前缀，同时决定 Init/Verify 域名
  AaduaneId    覆盖 RPC key id

响应字段：

  ok             验证码是否通过
  securityToken  本轮的安全 token
  VerifyCode     T001 表示通过，其余值说明未通过的原因
  VerifyResult   服务端判定结果
  certifyId      本轮挑战 ID
  elapsedMs      本轮总耗时

状态码：400 入参不合法（不消耗挑战）、429 超出并发上限、500 协议或运行错误。
验证码没通过仍然是一次正常往返，返回 200 且 ok=false。


四、命令行模式
----------------------------------------------------------------

在 cmd 或 PowerShell 里：

  AliSlider.exe                  快速 HTTP API（5 并发）并自动打开接口文档
  AliSlider.exe api              纯接口模式，不打印横幅，适合当后台服务
  AliSlider.exe solve            只做 Init/下载/识别，不发 Verify，不消耗挑战
  AliSlider.exe run              完整一轮，只发送一次 Verify
  AliSlider.exe --help           查看全部参数

常用参数：

  --port 8010                    换监听端口
  --host 0.0.0.0                 允许局域网访问（默认只监听本机）
  --max-concurrency 4            限制同时进行的挑战数
  --runtime-mode fast            快速模式：固定本进程画像并按并发容量预热
  --runtime-mode standard        标准模式：逐轮画像，不做设备会话预热
  --open-docs                    启动后在默认浏览器打开接口文档
  --timeout 30                   单步网络/子进程超时秒数

先跑 AliSlider.exe solve 是确认环境是否正常的最省事办法：它不发送 Verify，
因此不消耗挑战。


五、遇到问题
----------------------------------------------------------------

窗口一闪而过
  说明启动就失败了。改用 cmd 进入本目录执行 AliSlider.exe，错误会留在屏幕上。

提示端口无法监听
  端口被占用，换一个：AliSlider.exe --port 8010

提示找不到 Node
  分发包没有完整解压。请重新解压整个文件夹，不要只拷贝 exe。

杀毒软件报警
  PyInstaller 打出来的自解压程序常被误报。加白名单，或自行用
  packaging\build_windows.ps1 从源码重新构建。

中文显示成乱码
  用 Windows Terminal 打开，或在 cmd 里先执行 chcp 65001。
